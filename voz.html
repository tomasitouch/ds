Tu grabación
Cómo funciona este demo: usa la Web Speech API del navegador (Chrome / Edge) para transcribir en tiempo real. La grabación de audio se hace con MediaRecorder API. En la versión productiva, Phonos procesará el audio en el servidor con WhisperX para mayor precisión, detección de pausas y análisis fonético detallado. Toda la información de este demo queda solo en tu navegador.
